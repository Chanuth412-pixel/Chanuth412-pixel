## 🚀 Featured Projects

### 🤖 TF-Agent
Agentic Infrastructure as Code automation using AI agents.

- LangGraph-based multi-agent workflows
- Local LLM integration
- RAG-based context retrieval
- Terraform validation and automated correction

**Technologies:** Python, LangGraph, Ollama, Terraform

[View Repository](https://github.com/Chanuth412-pixel/tf-agent)

### 🩺 GloveXcel
An IoT-based wearable hand rehabilitation system designed for guided home physiotherapy and remote clinician monitoring.

- ESP32-based finger movement tracking
- Real-time BLE communication
- Interactive 3D hand visualization
- Patient and clinician applications

**Technologies:** ESP32, React, Three.js, Node.js, BLE, MongoDB, PostgreSQL

[View Repository](https://github.com/cepdnaclk/e21-3yp-GloveXcel)

### 🌐 AccessLens
A privacy-first browser extension that simplifies complex public-service forms through bilingual guidance and user-controlled form filling.

- Simplified form interfaces
- English and Sinhala guidance
- AI-assisted contextual help
- Privacy-focused form processing

**Technologies:** TypeScript, Browser Extensions, Backend, PostgreSQL

[View Repository](https://github.com/Chanuth412-pixel/AccessLens)

### 📊 PeraVerse Organizer Dashboard
A frontend dashboard for an exhibition crowd-management platform.

- Real-time crowd monitoring
- Event and building management
- Data visualization and analytics
- Live communication features

**Technologies:** React, TypeScript, Tailwind CSS, WebSockets

[View Repository](https://github.com/cepdnaclk/e21-co227-PeraVerse-Organizer-Dashboard-Core-Frontend)
